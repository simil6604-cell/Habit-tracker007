# Hintergrundmusik (optional)

Leg hier Tracks ab, für die du die Rechte auf der jeweiligen Plattform hast. Pro Clip wird ein Track
zufällig gewählt, leise (MUSIC_VOLUME=0.15) und automatisch leiser, sobald jemand spricht.
Ordner leer = Clip ohne Musik (Standard).

- `YouTube/`: z.B. Tracks aus der YouTube-Audiomediathek (YouTube Studio > Audiomediathek).
  Diese sind nur für YouTube freigegeben, nicht für TikTok oder Instagram.
- `TikTok/`, `Instagram/`: nur Musik, deren Lizenz diese Plattformen ausdrücklich abdeckt
  (z.B. kommerzielle Libraries mit Social-Media-Lizenz). Bekannte Songs führen zu Sperren/Stummschaltung.
